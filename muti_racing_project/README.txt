MUTI RACING PROJECT
Cara membuka:
1. Ekstrak file ZIP.
2. Buka folder muti_racing_project.
3. Klik dua kali index.html untuk membuka website di browser.

Catatan:
- Website menggunakan enam foto yang tersedia pada percakapan ini.
- Foto bertema motorsport digunakan sementara sebagai foto utama.
- Kursor dibuat dengan ilustrasi mobil balap sederhana berukuran 65 px. Jika ingin memakai gambar karakter chibi yang pernah dikirim, gambar tersebut perlu dimasukkan kembali saat revisi.
- Font Google Fonts memerlukan koneksi internet. Website tetap dapat dibuka tanpa koneksi, tetapi akan memakai font pengganti.
